# Codex CLI

AI-Native OS with 4D Git Visualization & VR/AR Support

[![npm version](https://badge.fury.io/js/%40zapabob%2Fcodex.svg)](https://badge.fury.io/js/%40zapabob%2Fcodex)
[![License: Apache-2.0](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

## Installation

### npm (Recommended)

`ash
npm install -g @zapabob/codex
`

### From Source

`ash
git clone https://github.com/zapabob/codex.git
cd codex/codex-cli
npm install
npm run build
npm install -g .
`

## Usage

`ash
# Interactive TUI
codex tui

# Launch GUI
codex gui

# Show help
codex --help
`

## Features

- **AI-Native OS**: The world's first AI operating system with kernel integration
- **4D Git Visualization**: xyz + time axis visualization
- **VR/AR Support**: Quest 2/3 and Vision Pro support
- **Sub-Agent System**: code-reviewer, test-gen, sec-audit, researcher
- **Deep Research**: Multi-source research with citations
- **MCP Integration**: Model Context Protocol support
- **CUDA Acceleration**: GPU-accelerated operations

## Commands

| Command | Description |
|---------|-------------|
| codex tui | Launch Terminal User Interface |
| codex gui | Launch Graphical User Interface |
| codex --help | Show help information |

## Requirements

- Node.js >= 18.0.0
- npm >= 9.0.0
- Rust >= 1.80 (for building from source)

## Supported Platforms

- Linux x64/arm64
- macOS x64/arm64 (Intel/Apple Silicon)
- Windows x64/arm64
