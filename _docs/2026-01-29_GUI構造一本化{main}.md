## 🔧 技術的詳細

### 認証システム

**実装方式**: JWT + SQLite

**セキュリティ**:
- パスワード: bcryptハッシュ化（DEFAULT_COST）
- トークン: JWT（24時間有効期限）
- セッション: SQLiteデータベースで管理

**フロー**:
1. ユーザーがログイン → Rustバックエンドで認証
2. JWTトークン発行 → フロントエンドのlocalStorageに保存
3. 以降のリクエストでトークンを使用（実装予定）

### Plan管理システム

**実装方式**: CLI経由 + SQLiteキャッシュ

**フロー**:
1. フロントエンド → RustバックエンドAPI
2. Rustバックエンド → `codex Plan`コマンド実行
3. 結果をJSON形式で返却
4. メタデータをSQLiteにキャッシュ（オプション）

### 可視化システム

**実装方式**: 統合コンポーネント + RustバックエンドAPI

**機能**:
- 3D/4D Git可視化（デスクトップ）
- VR/AR可視化（WebXR）
- ハンドトラッキング
- 空間オーディオ

## 🐛 既知の問題と解決策

### 1. 認証トークンの送信

**問題**: 現在、認証トークンをリクエストヘッダーに含めていない

**解決策**: 
- `apiClient`に認証トークンを自動付与する機能を追加
- または、各APIリクエストで`Authorization`ヘッダーを追加

### 2. SQLiteデータベースの初期化

**問題**: データベースが自動的に初期化されない

**解決策**: 
- 初回起動時に自動的にテーブルを作成するように実装済み
- マイグレーションスクリプトも提供

### 3. Planデータの移行

**問題**: SupabaseからPlanデータを移行する必要がある

**解決策**: 
- 移行スクリプトを提供（`scripts/migrate-supabase-to-sqlite.ps1`）
- 手動移行手順をドキュメント化
