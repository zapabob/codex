## メモ

### 技術的詳細
- **ビルド高速化**: 平均30-50%のビルド時間短縮（差分ビルド時）
- **プロセス管理**: psutilを使用した安全なプロセス終了
- **キャッシュ戦略**: 変更ベースのインテリジェントリビルド判定
- **クロスプラットフォーム**: Windows PowerShell + Unixシェルの統合

### 使用方法
```bash
# 高速ビルド
just fast-build release

# 完全ビルド＆インストール
just build-install

# PowerShell直接インストール
just install-kill codex-rs/target/release/codex.exe C:/bin/codex.exe
```
