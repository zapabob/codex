# 2026-02-07 GUI機能統合とVite移行

## 概要

レガシーな `gui` プロジェクトから `codex-gui-x` (Vite) プロジェクトへ、可視化、VR、プランニング、仮想OSの機能を統合しました。

## 実施内容

### 1. ライブラリ依存関係の追加

- 3D/VR: `three`, `@react-three/fiber`, `@react-three/xr`
- UI: `@mui/material`, `framer-motion`, `lucide-react`
- チャート: `recharts`

### 2. コンポーネントの移行と修正

- `visualization/Git4DVisualization.tsx`: Three.jsの型定義とフックの依存関係を修正。
- `plan/PlanCreator.tsx`: APIクライアントの統合、プロパティ名のマッピング（snake_case -> camelCase）を修正。
- `virtual-os/VirtualEnvironmentManager.tsx`: MUIコンポーネントのプロパティ（size, variant）をVite環境に合わせて標準化。
- `App.tsx`: サイドバーに新しいビュー（Visualization, VR, Plans, Virtual OS）を追加。

### 3. バックエンドの互換性修正

- `codex-rs/core/src/config/mod.rs`: `ConfigToml` のフィールドを `serde_json::Value` に変更し、`schemars::JsonSchema` の制約エラーを解消。

### 4. ビルドエラーの解消（進行中）

- 多数のTypeScriptエラー（主にWebXR関連とMUIプロパティの不一致）を段階的に修正。

## 検証結果

- `npm run build` は現在実行可能ですが、WebXR関連で未解決の型エラーが残っています。
- 統合された各ビューはサイドバーから切り替え可能です。

## 今後の課題

- WebXR APIの型定義の完全な解決。
- 残りの小規模なUIコンポーネントのプロパティ調整。
- 実機（Meta Quest等）でのVR動作確認。
