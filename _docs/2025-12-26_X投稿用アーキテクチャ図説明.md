# X投稿用 簡易アーキテクチャ図

## 📐 図の構成

### レイヤー構造（左→右のフロー）

```
🖥️ Client Layer
    ↓ RPC
⚙️ Core Runtime (v2.7.0)
    ↓ API
🤖 LLM Providers
    ↑ Metrics
📊 Observability
```

## 🎯 主要コンポーネント

### 1. Client Layer（クライアント層）
- **CLI**: コマンドラインインターフェース
- **TUI**: ターミナルUI（22個のスラッシュコマンド）
- **IDE**: VSCode/Cursor統合

### 2. Core Runtime（コアランタイム）
- **Token Budget**: スレッドセーフなトークン予算管理
- **Multi-Agent**: マルチエージェント並列実行（2.6x高速化）
- **Unified Exec**: 統一実行システム

### 3. LLM Providers（LLMプロバイダー）
- **OpenAI**: GPT-5-codex
- **Gemini**: Google Gemini 2.5
- **Anthropic**: Claude 3.5+

### 4. Observability（オブザーバビリティ）
- **OpenTelemetry**: トレーシングとメトリクス

## 🎨 視覚的ポイント

- **色分け**: 各レイヤーを異なる色で区別
- **太線**: Core Runtimeを強調（最重要コンポーネント）
- **矢印**: データフローを明確に表示
- **簡潔**: X投稿用に必要最小限の情報のみ

## 📊 数値ハイライト

- **2.6x**: マルチエージェント並列実行の高速化
- **22**: TUIスラッシュコマンド数
- **v2.7.0**: 現在のバージョン

## 🔗 X投稿との組み合わせ

この図は以下の投稿文と組み合わせて使用：

```
【LLMOps評価】Codex v2.7.0: 4.2/5.0⭐
✅ エンタープライズレベルのトークン予算管理（スレッドセーフ、エージェント別制限）
✅ マルチエージェント並列実行2.6x高速化
✅ OpenTelemetry統合で完全なオブザーバビリティ

```

## 📝 生成方法

1. Mermaidファイル: `architecture-v2.7.0-simple-x.mmd`
2. PNG生成: `mmdc -i architecture-v2.7.0-simple-x.mmd -o architecture-v2.7.0-simple-x.png -w 1200 -H 800 -b transparent`
3. SVG生成: `mmdc -i architecture-v2.7.0-simple-x.mmd -o architecture-v2.7.0-simple-x.svg`
