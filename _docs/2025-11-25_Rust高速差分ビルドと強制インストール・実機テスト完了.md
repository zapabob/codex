## 実行コマンド

### Phase 1: 高速差分ビルド

```powershell
cd codex-rs
.\clean-build-install.ps1 -SkipClean
```

### Phase 2: 強制インストール

```powershell
# 既存バイナリを使用してインストール
$installPath = "$env:USERPROFILE\.cargo\bin\codex.exe"
Get-Process codex -ErrorAction SilentlyContinue | Stop-Process -Force
Copy-Item "target\release\codex.exe" $installPath -Force
codex --version
```

### Phase 3: Node.jsスクリプト確認

node scripts/build-and-install.js --skip-clean
