**実装内容**:

- レジストリ/Launch Agent/Desktop Entryによる設定

**主な機能**:

- Launch Agent: `~/Library/LaunchAgents/com.codex.autostart.plist`
- `launchctl`コマンドでロード/アンロード

**Linux**:
- Desktop Entry: `~/.config/autostart/codex.desktop`
- XDG Autostart仕様に準拠

**バックグラウンドプロセス管理**:
```rust
pub struct BackgroundProcessManager {
    process_id: Option<u32>,
}

impl BackgroundProcessManager {
    pub fn start(&mut self, command: &str, args: &[&str]) -> Result<()>
    pub fn stop(&mut self) -> Result<()>
    pub fn is_running(&self) -> bool
}
```

## 技術詳細

### 自動起動実装

1. **Windows**:
   - レジストリ操作による自動起動設定
   - `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`にエントリ追加
   - 実行ファイルのパスを値として設定

2. **macOS**:
   - Launch Agent plistファイルの作成
   - `launchctl load/unload`コマンドで管理
   - `RunAtLoad`キーで自動起動を制御

3. **Linux**:
   - Desktop Entryファイルの作成
   - XDG Autostart仕様に準拠
   - `~/.config/autostart/`ディレクトリに配置

### 通知実装

1. **Windows Toast Notifications**:
   - Windows 10+のToast Notification APIを使用
   - XMLテンプレートによる通知定義
   - PowerShellスクリプト経由で表示

2. **macOS Notifications**:
   - `osascript`コマンドでAppleScript実行
   - 通知タイプに応じたサウンド設定
   - タイトルと本文の設定

3. **Linux Notifications**:
   - `notify-send`コマンド（GNOME/KDE対応）
   - `dbus-send`コマンド（フォールバック）
   - D-Bus経由で通知表示

### バックグラウンドプロセス管理

- Windows: `taskkill`コマンドでプロセス終了
- macOS/Linux: `kill -9`コマンドでプロセス終了
- プロセスIDの追跡と管理
