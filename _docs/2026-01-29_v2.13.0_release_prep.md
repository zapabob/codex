## 技術的詳細

### バージョン管理

`codex-rs` はワークスペース構成となっており、`[workspace.package]` でバージョンを一元管理しているため、ルートの `Cargo.toml` 更新のみで全クレートに適用されます。

### ビルドプロセス

- Command: `cargo build --release`
- Target: `x86_64-pc-windows-msvc` (想定)
- Output: `target/release/codex.exe`
