## 修正内容

### rand APIの更新

```rust
// Before: 古いAPI (Rust 2021以前)
let jitter: f64 = rand::rng().random_range(0.9..1.1);

// After: Rust 2024ベストプラクティス
let jitter: f64 = rand::thread_rng().gen_range(0.9..1.1);
```

### 改善点

- **安全性**: `gen_range()` は範囲チェックを行い、境界値の誤りを防ぐ
- **パフォーマンス**: `thread_rng()` はスレッドローカルなRNGを使用し、ロック競合を避ける
- **可読性**: 範囲指定が明示的で意図が明確
- **型安全性**: ジェネリクスを使用した型推論が適切
