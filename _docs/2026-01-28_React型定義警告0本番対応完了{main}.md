  - `prism-web/.eslintrc.json`: 同様に`error`レベルに変更

  ```json

      "@typescript-eslint/no-unused-vars": "error",
      "react-hooks/exhaustive-deps": "error"
    }
  }
  ```

#### 2.2 TypeScript設定の強化
- **更新ファイル**: 全`tsconfig.json`ファイル
- **追加設定**:
  - `noImplicitAny: true`
  - `strictNullChecks: true`
  - `noUnusedLocals: true`
  - `noUnusedParameters: true`
  - `noImplicitReturns: true`
  - `noFallthroughCasesInSwitch: true`

#### 2.3 any型の段階的排除
- **型定義ファイル作成**:
  - `gui/src/lib/types/api.ts`: API型定義集約（新規作成）
    - `APIRequest<T>`, `APIResponse<T>`, `APIError`
    - `AccountInfo`, `AgentContext`, `AgentResult`
    - `Tool`, `Session`, `Task`, `FuzzySearchResult`
    - `WebSocketMessage`
- **主要ファイルのany型置換**:
  - `gui/src/lib/api/client.ts`: 主要な`any`型を適切な型に置換
    - `getAccount()`: `Promise<any>` → `Promise<AccountInfo>`
    - `runAgent()`: `(context: any)` → `(context: AgentContext)`
    - `connectWebSocket()`: `(message: any)` → `(message: WebSocketMessage)`
    - `fuzzyFileSearch()`: `Promise<any[]>` → `Promise<FuzzySearchResult[]>`
  - `gui/src/lib/types/index.ts`: `APIRequest<T = any>` → `APIRequest<T = unknown>`
