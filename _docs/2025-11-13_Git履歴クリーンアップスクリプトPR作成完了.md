## 🔧 スクリプトの特徴

### 主な機能

1. **ストリーミング処理**: 大きなリポジトリでもメモリ効率的に処理
2. **バイナリデータ対応**: `fast-export`のバイナリデータを正しく処理
3. **進捗表示**: `tqdm`を使用した視覚的な進捗表示
4. **ログ記録**: 詳細なログを`.git/fix-invalid-paths.log`に記録
5. **エラーハンドリング**: 適切なエラーメッセージと復旧手順の提示

### 処理フロー

1. **バックアップブランチの作成**: 作業前に現在の状態をバックアップ
2. **第1パス**: スキップする`mark`番号を収集
   - 無効なパス名を含むファイル
   - 大きなファイル（node_modules、.next/cache、.pack、.nodeなど）
3. **第2パス**: フィルタリング処理
   - スキップ対象の`blob`ブロックを削除
   - バイナリデータを正しく処理
4. **fast-import**: フィルタリングされた履歴を再インポート

### PR説明文の例

```markdown
## 概要

Git履歴から無効なパス名と大きなファイルを削除するスクリプトを追加しました。

## 問題

GitHubの100MBファイルサイズ制限に抵触する大きなファイルや、Windowsで無効なパス名（`<`, `>`, `:`, `"`, `|`, `?`, `*`, `\`など）を含むファイルがGit履歴に残っている場合、リモートへのプッシュが失敗します。

## 解決策

このスクリプトは`git fast-export`と`git fast-import`を使用して履歴を書き換え、無効なパス名と大きなファイルを履歴から削除します。

## 特徴

- ストリーミング処理で大きなリポジトリでもメモリ効率的
- バイナリデータを正しく処理
- 進捗表示（tqdm）
- 詳細なログ記録
- Windowsエンコーディング対応
- 自動バックアップブランチ作成

## 使用方法

```bash
python scripts/fix-invalid-paths-fast-export-streaming.py
```

## 注意事項

⚠️ このスクリプトはGit履歴を書き換えます。以下の点に注意してください：

1. バックアップ: スクリプトは自動的にバックアップブランチを作成します
2. 強制プッシュ: 履歴を書き換えた後は、`git push --force`が必要です
3. 他の開発者: 履歴を書き換えるため、他の開発者と調整が必要な場合があります
4. 処理時間: 大きなリポジトリでは処理に数時間かかる場合があります
```

## 📊 技術的詳細

### 実装のポイント

1. **二段階フィルタリング**:
   - 第1パス: スキップ対象の`mark`番号を収集
   - 第2パス: `blob`ブロック全体をスキップ

2. **バイナリデータ処理**:
   - `fast-export-filtered`ファイルをバイナリモードで保存
   - `fast-import`プロセスにバイナリモードでデータを渡す

3. **エラーハンドリング**:
   - `BrokenPipeError`の適切な処理
   - 非同期`stderr`読み取り
   - プロセス終了の検出
