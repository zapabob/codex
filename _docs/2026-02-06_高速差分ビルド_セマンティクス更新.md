# 2026-02-06 高速差分ビルド・セマンティクス更新

## 概要

Codexプロジェクトのセマンティクスバージョンを `2.13.0` から `2.14.0` へ引き上げ、ビルド・インストールスクリプト `ultra-fast-build-install.ps1` を高速化・最適化しました。

## 変更内容

### セマンティクスバージョンの更新

- `codex-rs/Cargo.toml` の `workspace.package.version` を `2.14.0` に更新。

### ビルド・インストールスクリプトの強化

- **スクリプトバージョン**: `1.0.0` → `1.3.0`
- **高速差分検知**: SHA256ハッシュの計算を廃止し、`LastWriteTime`（ファイルの最終更新日時）による比較に変更。大規模なコードベースでも瞬時に差分を検知可能。
- **スマートインストール**: インストール先とソースのバイナリのタイムスタンプを比較し、更新が必要な場合のみ上書き（コピー＆ペースト）を実行。無駄なI/Oを削減。
- **ビルドの安定化**: 単一の `cargo build` コマンドによる一括ビルドと、ビルド前の PDB 自動削除により、並列ビルド時のロックや破損を防止。
- **プロセス終了のアグレッシブ化**: `taskkill /F /T` による瞬時のプロセス停止。
- **不具合修正**: PowerShellの予約変数 `$pid` との衝突を避けるため、ループ変数を `$lockingPid` に変更。

- [x] `Cargo.toml` のバージョン整合性確認。
- [x] PowerShellスクリプトの構文チェックおよびロジックの最適化確認。
- [x] `Install-BinaryAtomic` のエラーハンドリング（ファイルロック時の再試行ロジック）の正常性確認。
