#### 修正2: `windows-sandbox-rs`モジュール構造の修正

`sandbox_users.rs`が`lib.rs`と`setup_main_win.rs`の両方でモジュールとして宣言されていたため、以下を修正:

1. `lib.rs`の`windows_modules!`マクロから`sandbox_users`を削除
2. 関連する`pub use sandbox_users::`エクスポートを削除
3. `sandbox_users.rs`に`log_line`関数をローカル実装

```rust
// sandbox_users.rs に追加
fn log_line(log: &mut File, msg: &str) -> Result<()> {
    let ts = chrono::Utc::now().to_rfc3339();
    writeln!(log, "[{ts}] {msg}").map_err(|err| {
        anyhow::Error::new(SetupFailure::new(
            SetupErrorCode::HelperLogFailed,
            format!("failed to write setup log line: {err}"),
        ))
    })?;
    Ok(())
}
```

4. `SandboxUserRecord`、`SandboxUsersFile`、`SetupMarker`構造体を`pub`に変更
