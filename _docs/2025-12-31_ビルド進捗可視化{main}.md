### `codex-rs/check_build_progress.ps1`

**機能**:

**使用方法**:
```powershell
cd codex-rs
.\check_build_progress.ps1
```

## 進捗表示の特徴

1. **リアルタイム更新**: 2秒ごとに進捗を更新
2. **視覚的な進捗バー**: `█`と`░`で進捗を表示
3. **時間情報**: 経過時間と推定残り時間を表示
4. **リソース監視**: CPU使用時間とメモリ使用量を表示
5. **自動検出**: ビルドファイル生成を自動検出
