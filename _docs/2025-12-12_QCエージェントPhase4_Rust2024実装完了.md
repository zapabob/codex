## 🔧 使用方法

### TUIからの利用
```bash
# Codex TUI起動
codex

# Planコマンド実行
/plan
# → 品質保証統合メニュー表示
```

### プログラムからの利用
```rust
use codex_core::qc::{monitoring::RealTimeQualityMonitor, prediction::QualityPredictor, improvement::AutomaticQualityImprover};

// リアルタイム監視
let monitor = RealTimeQualityMonitor::<10, 100>::new(config);
monitor.start_monitoring(rules).await?;

// ML予測
let predictor = QualityPredictor::new();
let prediction = predictor.predict_quality(&features, &model_id).await?;

// 自動改善
let improver = AutomaticQualityImprover::new(analyzer, transformer, predictor, risk_assessor, 4);
let plan = improver.generate_improvement_plan(&files, &requirements, RiskLevel::Medium).await?;
let result = improver.execute_improvement_plan(&plan, false).await?;
```
