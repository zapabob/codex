## 実装内容

### 1. Rust 2024ベストプラクティス適用

#### 型エイリアスの改善
- `lib.rs`に`Result<T>`型エイリアスを追加
- コレクション型の共通エイリアスを追加（`HashMap`, `HashSet`, `VecDeque`）

#### Importの整理
- `resource_monitor.rs`のimportをRust 2024スタイルに整理
- 重複importの除去とグループ化

#### エラー処理の改善
- `agents/runtime.rs`のResponseEvent使用を一時的にコメントアウト
- Rust 2024のwhile-let chainsを使用したストリーム処理の準備

### 2. 型定義の改善

#### lib.rsの拡張
```rust
pub type Result<T> = anyhow::Result<T>;
pub type HashMap<K, V> = std::collections::HashMap<K, V>;
pub type HashSet<T> = std::collections::HashSet<T>;
pub type VecDeque<T> = std::collections::VecDeque<T>;
```

#### モジュール構造の整理
- `agents`, `plan`モジュールをlib.rsに追加
- モジュール間の依存関係を明確化

### 3. コンパイルエラー修正

#### sysinfo APIの更新
- `processors()` → `cpus()` に変更
- `SystemExt` traitの使用を削除
- refresh_all()の明示的な呼び出しを追加

#### Cargo.tomlの依存関係調整
- ringバージョンを0.16にダウングレード（aws-lc-sys回避）
- cmakeバージョンを調整

### 4. 警告対応
