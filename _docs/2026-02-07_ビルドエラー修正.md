# 2026-02-07\_ビルドエラー修正

Rustのテストコードにおけるビルドエラーの修正、およびGitHub Workflowのリンター警告（secretsアクセス構文）の修正を行いました。

## 修正内容

### Rust (codex-rs)

- **rate_limit.rs**: `RateLimitWarningState` の `secondary_index` と `primary_index` フィールドを `pub(crate)` に変更し、テストコードからアクセス可能にしました。
- **chatwidget/tests.rs**: `UnifiedExecProcessSummary` から削除された `recent_chunks` フィールドの代入を削除しました。
- **history_cell/tests.rs**: `UnifiedExecProcessDetails` から削除された `recent_chunks` フィールドの代入を削除しました。

### GitHub Workflows

- **issue-labeler.yml**: secretへのアクセス構文を `secrets['KEY']` から `secrets.KEY` に変更し、リンター警告を解消しました。
- **rust-release.yml**:
  - Azure Trusted SigningおよびAppleコード署名の各種シークレットへのアクセス構文を修正しました。
  - `DEV_WEBSITE_VERCEL_DEPLOY_HOOK_URL` のアクセス構文も同様に修正しました。

## 検証結果

- `cargo check -p codex-tui --tests` を実行し、ビルドエラーが解消されたことを確認しました。
- `rust-release.yml` の `shell-tool-mcp.yml` 呼び出しパスがリポジトリ内に存在することを確認しました。
