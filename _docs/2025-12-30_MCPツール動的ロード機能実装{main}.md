**作成日時**: 2025-12-30  
**ワークツリー**: main

## 📋 実装概要

MCPツールを実行時に動的にロード・アンロードできる包括的なシステムを実装しました。さらに、トークン節約機能として、必要なツールのみを選択的にロードし、使用頻度に基づく自動アンロード、ツール説明の圧縮、プロンプトへの選択的追加を実装しました。

---

## 🎯 実装内容

### 1. コア動的ロード機能

#### DynamicMcpLoader (`codex-rs/core/src/mcp_dynamic_loader.rs`)

**実装機能**:
- ✅ `add_server()` - 実行時にMCPサーバーを追加
- ✅ `remove_server()` - 実行時にMCPサーバーを削除
- ✅ `reload_server()` - サーバー設定をリロード
- ✅ `list_servers()` - 動的ロードされたサーバー一覧
- ✅ `get_server_state()` - サーバー状態の取得

**主要構造**:
```rust
pub struct DynamicMcpLoader {
    connection_manager: Arc<RwLock<McpConnectionManager>>,
    server_states: Arc<Mutex<HashMap<String, ServerState>>>,
    // ...
}
```

## 🚀 使用方法

### 1. 設定ファイルでの有効化

`.codex/config.toml`:
```toml
[mcp_dynamic_loading]
enabled = true
plugin_dir = ".codex/mcp-plugins"
watch_config_file = true
api_server_port = 8080

[mcp_token_optimization]
enabled = true
auto_unload_enabled = true
auto_unload_threshold_secs = 3600
compress_descriptions = true
max_tools_per_prompt = 50
```

### 2. プラグインの作成

`.codex/mcp-plugins/my-plugin/plugin.toml`:
```toml
[plugin]
name = "my-plugin"
version = "1.0.0"
description = "My MCP plugin"
enabled = true
```

`.codex/mcp-plugins/my-plugin/server.toml`:
```toml
command = "node"
args = ["server.js"]
enabled = true
```

### 3. CLIコマンドの使用

```bash
# サーバーを動的に追加
codex mcp dynamic add --name my-server --command node --args server.js

# サーバー一覧
codex mcp dynamic list

# サーバーを削除
codex mcp dynamic remove --name my-server

# ファイル監視を開始
codex mcp dynamic watch
```

### 4. APIエンドポイントの使用

```bash
# サーバー追加
curl -X POST http://localhost:8080/api/mcp/servers \
  -H "Content-Type: application/json" \
  -d '{"name": "my-server", "config": {...}}'

# サーバー一覧
curl http://localhost:8080/api/mcp/servers
```

## 💡 トークン節約効果

### 節約戦略

1. **使用頻度ベースの自動アンロード**: 1時間未使用のツールを自動アンロード
2. **タスクベースの選択的ロード**: 必要なツールのみをロード
3. **ツール説明の圧縮**: 50-70%のトークン削減
4. **プロンプトへの選択的追加**: 関連ツールのみをプロンプトに含める

### 期待される効果

- **説明圧縮**: 50-70%削減
- **選択的ロード**: 30-50%削減
- **自動アンロード**: 未使用ツールの蓄積を防止

**例**: 100ツール（各200トークン）の場合
- 最適化なし: 20,000トークン
- 圧縮のみ: 6,000-10,000トークン
- 完全最適化: 3,000-7,000トークン（65-85%削減）

## 🔧 技術的詳細

### アーキテクチャ

```
Codex Session
    └── SessionServices
        ├── McpConnectionManager (既存)
        └── DynamicMcpLoader (新規)
            ├── McpFileWatcher
            ├── McpPluginLoader
            ├── McpApiServer
            ├── McpTokenOptimizer
            ├── SelectiveToolLoader
            └── McpPromptBuilder
```

### データフロー

1. **動的ロード**:
   ```
   User/API/CLI → DynamicMcpLoader → McpConnectionManager → MCP Server
   ```

2. **ファイル監視**:
   ```
   File Change → McpFileWatcher → DynamicMcpLoader → Reload
   ```

3. **プラグインロード**:
   ```
   Plugin Dir → McpPluginLoader → DynamicMcpLoader → Load
   ```

4. **トークン最適化**:
   ```
   Tool Usage → McpTokenOptimizer → Track → Auto-unload
   Task → SelectiveToolLoader → Select Tools → Load
   Prompt → McpPromptBuilder → Compress → Build
   ```
