## 🔍 技術詳細

### Next.js開発サーバーのホスト設定

**`-H 0.0.0.0`オプション**:
- `0.0.0.0`は全ネットワークインターフェースでリッスンすることを意味
- `localhost`（127.0.0.1）のみでは外部デバイスからアクセス不可
- `0.0.0.0`にすることで、同一ネットワーク内のすべてのデバイスからアクセス可能

### ファイアウォール設定

**Windows Defender Firewall**:
- ポート3000のインバウンド接続を許可
- ルール名: "Next.js Dev Server (Port 3000)"
- プロトコル: TCP
- ポート: 3000
- アクション: Allow

### IPアドレス取得ロジック

```powershell
$ipAddresses = @(Get-NetIPAddress -AddressFamily IPv4 | Where-Object {
    $_.InterfaceAlias -notlike '*Loopback*' -and 
    $_.IPAddress -notlike '169.254.*' -and
    $_.IPAddress -notlike '127.*'
} | Select-Object IPAddress, InterfaceAlias)
```

**フィルタ条件**:
- Loopbackインターフェースを除外
- リンクローカルアドレス（169.254.*）を除外
- ローカルホスト（127.*）を除外

## 🐛 トラブルシューティング

### Quest 2からアクセスできない場合

1. **IPアドレス確認**
   ```powershell
   Get-NetIPAddress -AddressFamily IPv4 | Where-Object {$_.InterfaceAlias -notlike '*Loopback*'}
   ```

2. **ファイアウォール確認**
   ```powershell
   Get-NetFirewallRule -DisplayName "*Next.js*"
   ```

3. **ポート3000確認**
   ```powershell
   Get-NetTCPConnection -LocalPort 3000
   ```

4. **ネットワーク確認**
   - PCとQuest 2が同じWi-Fiネットワークに接続されていることを確認
   - 5GHz Wi-Fiを使用（推奨）
