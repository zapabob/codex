# 2026-01-30*v2.13.0*リリースビルド・インストール・検証完了

## 実装概要

Codex v2.13.0の正式リリースに向けた最終ビルド、インストール、および実機検証を実施。
`codex-core`におけるコンパイルエラー（SandboxTransformErrorの型不一致等）を完全に解消し、高速差分ビルドによるリリースバイナリの生成と、特定ディレクトリへの上書きインストールを完了した。

## 修正・変更内容

### `codex-rs` (Backend)

- **`codex-core` コンパイル修正**:
  - `exec.rs` および `sandboxing/mod.rs` において、欠落していた `SandboxTransformError::Transform` バリアントを追加し、エラーハンドリングを統一。
  - `codex.rs` での `ToolRouter` 構築時の型不一致エラーを修正。
- **ビルドスクリプト (`fast_build_install_test.py`) 強化**:
  - `cargo clean` をスキップし、高速差分ビルドをデフォルト化。
  - `codex-tui` のビルドと実機テストプロセスを追加。
  - Windows環境でのプロセスロックを確実に解除する `taskkill` ロジックの実装。

### `gui` (Frontend)

- **ライブラリ更新対応**:
  - `@react-three/xr` v6への移行に伴う破壊的変更（`createXRStore`, `XR`コンポーネントの `store` プロップ必須化等）への暫定対応。
  - `lucide-react` のアイコン名修正 (`Vr` -> `Box`)。
  - 未使用変数 (`router`) の削除によるビルドエラーの解消。
