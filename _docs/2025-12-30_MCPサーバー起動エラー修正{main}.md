# MCPサーバー起動エラー修正

**作成日時**: 2025-12-30  
**ワークツリー**: main

---

## 📋 問題概要

Codex起動時に以下のMCPサーバーが起動に失敗していました：

1. `codex-gemini-mcp`: program not found
2. `codex-research`: handshaking failed
3. `codex-agent`: handshaking failed
4. `codex-supervisor`: handshaking failed
5. `playwright`: 起動失敗
6. `context7`: 起動失敗

また、`web_search`が非推奨で`web_search_request`機能フラグを使用する必要があるという警告も表示されていました。

---

## 🔧 修正内容

### 1. 機能フラグの修正

**変更前**:
```toml
[features]
# web_search = true  # 非推奨
```

**変更後**:
```toml
[features]
web_search_request = false  # 必要に応じて有効化
```

### 2. MCPサーバー設定の修正

#### codex-gemini-mcp
- **問題**: `codex-gemini-mcp`コマンドが見つからない
- **対応**: `enabled = false`に設定して無効化

#### codex-research, codex-agent, codex-supervisor
- **問題**: これらは`codex`コマンドのサブコマンド（`research`, `agent`, `supervisor`）として実装されているが、MCPサーバーとして動作しない
- **対応**: `enabled = false`に設定して無効化
- **備考**: これらはCLIコマンドとして使用可能（例: `codex research <topic>`）

#### playwright, context7
- **問題**: handshaking failed
- **対応**: 設定は維持（npxコマンドのパスは正しい）
- **備考**: ネットワーク接続やパッケージのインストール状況を確認する必要がある可能性

---

## 📝 修正後の設定

```toml
# ==================== 機能フラグ ====================
[features]
web_search_request = false  # 必要に応じて有効化

# Codex Supervisor - 無効化
[mcp_servers.codex-supervisor]
enabled = false

# Codex Research - 無効化
[mcp_servers.codex-research]
enabled = false

# Codex Agent - 無効化
[mcp_servers.codex-agent]
enabled = false

# Gemini CLI - 無効化
[mcp_servers.codex-gemini-mcp]
enabled = false
```

## 💡 今後の対応

### codex-gemini-mcp
- `codex-gemini-mcp`コマンドをインストールするか、代替手段を検討
- または、`codex-gemini-cli-mcp-server.exe`を使用（設定に既に定義あり）

### codex-research, codex-agent, codex-supervisor
- これらをMCPサーバーとして使用する場合は、`mcp-server`サブコマンド経由で実装する必要がある
- 現在はCLIコマンドとして使用可能

### playwright, context7
- ネットワーク接続を確認
- パッケージのインストール状況を確認（`npx @playwright/mcp@latest`など）
- タイムアウト設定を調整する可能性

- `web_search`を`web_search_request`に変更
- 動作しないMCPサーバーを無効化
- 主要なMCPサーバーは正常に動作
