バイナリファイル（`codex.exe`、`codex`など）が必要な場合、`vendor`ディレクトリがパッケージに含まれているか確認してください。

```bash

```

`vendor`ディレクトリが含まれていない場合、バイナリファイルを手動で追加する必要があります。

### 2. npm認証

- **手動公開**: `npm login`でログインが必要
- **GitHub Actions**: OIDC Trusted Publishingを使用（認証不要）

### 3. スコープパッケージの公開

`@zapabob/codex`はスコープパッケージなので、`--access public`フラグが必要です。

## 🔍 トラブルシューティング

### エラー: `ENEEDAUTH`

**原因**: npmにログインしていない

**解決方法**:
```bash
npm login
```

### エラー: `EPERM` または `EACCES`

**原因**: パッケージ名が既に使用されている、または権限がない

**解決方法**:
- npmアカウントに`@zapabob`スコープの公開権限があるか確認
- パッケージ名が正しいか確認（`@zapabob/codex`）

### エラー: `ETARGET` または `EINVALIDTAG`

**原因**: バージョンが既に公開されている

**解決方法**:
- バージョンを更新（例: `2.2.1`）
- または既存のバージョンを削除（非推奨）
