## 🆕 新機能詳細

### LSP統合
- rust-analyzer、TypeScript Server、Python Language Server等との統合
- リアルタイム診断情報の取得と配信
- コード補完、ホバー情報、シンボル検索の統合

### Ultrathink Mode
- 複数ステップの深い推論チェーン実行
- 推論ステップ間の依存関係管理
- 推論結果の検証と反証

### Microsoft 365統合
- Microsoft Graph API統合
- OAuth 2.0認証フロー
- Word、Excel、PowerPoint、Outlook API呼び出し

### Skills for Organizations
- 組織内Skillsの共有
- Skillsのバージョン管理
- Skillsの権限管理
