## 🎯 問題解決

**元の問題**: GUIがモックアップ実装で、CLIとの接続ができていない

**根本原因**:
- GUIのAPIクライアントが `http://localhost:8787` の存在しないエンドポイントを呼び出し
- プロトコルクライアントを使用せず、ハードコードされたモックレスポンスを返却
- CLIにRPCサーバー機能が実装されていない

### 2. GUI APIクライアントの完全書き換え

**修正ファイル**: `gui/src/lib/api/client.ts`

**変更点**:
- **プロトコル**: HTTP/REST → WebSocket RPC
- **接続先**: `http://localhost:8787` → `ws://localhost:3001`
- **実装方式**: モックレスポンス → 実際のCLI通信

**新アーキテクチャ**:
```typescript
class CodexAPIClient {
  private protocolClient: WebSocket;
  private isConnected = false;
  private requestId = 0;
  private pendingRequests = new Map<string, PendingRequest>();

  constructor() {
    this.initializeConnection(); // WebSocket接続初期化
  }

  private async sendRequest(method: string, params: any): Promise<any> {
    // JSON-RPC 2.0 over WebSocket
    const request = {
      jsonrpc: '2.0',
      id: (++this.requestId).toString(),
      method,
      params,
    };
    // ... WebSocket送信処理
  }

```

### 4. フォールバック機構

**接続失敗時の対応**:
- CLIサーバーが利用できない場合、モックレスポンスを返却
- 開発・テスト環境での利便性確保
- 本番環境ではCLIサーバーの起動を前提

```typescript
async getAgents(): Promise<Agent[]> {
  try {
    const result = await this.sendRequest('agent.list');
    return result.agents || this.getDefaultAgents();
  } catch (error) {
    console.warn('CLI server not available, using default agents:', error);
    return this.getDefaultAgents(); // フォールバック
  }
}
```

## 📋 技術詳細

### WebSocket RPCプロトコル

**リクエスト形式**:
```json
{
  "jsonrpc": "2.0",
  "id": "123",
  "method": "agent.list",
  "params": {}
}
```

**レスポンス形式**:
```json
{
  "jsonrpc": "2.0",
  "id": "123",
  "result": {
    "agents": [...]
  }
}
```

**サポートメソッド**:
- `account.*` - 認証関連
- `conversation.*` - 会話管理
- `agent.*` - エージェント操作
- `mcp.*` - MCP接続管理
- `system.*` - システムメトリクス
- `exec.*` - コマンド実行
- `fs.*` - ファイル操作

### 接続管理

**自動再接続**:
```typescript
this.protocolClient.onclose = () => {
  this.isConnected = false;
  setTimeout(() => this.initializeConnection(), 5000); // 5秒後に再接続
};
```

**リクエストタイムアウト**:
```typescript
const timeout = setTimeout(() => {
  reject(new Error('Request timeout'));
}, 30000); // 30秒
```

**エラーハンドリング**:
```typescript
this.protocolClient.onerror = (error) => {
  console.error('WebSocket error:', error);
  this.isConnected = false;
};
```
