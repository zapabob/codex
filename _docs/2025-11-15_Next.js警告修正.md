## 🐛 修正した警告

### Warning 1: framer-motion motion() 非推奨

**警告メッセージ**:
```
motion() is deprecated. Use motion.create() instead.
```

**原因**: framer-motionの`motion()`関数が非推奨になり、`motion.create()`を使用する必要がある

**修正箇所**:
- `gui/src/components/atoms/Card.tsx`: `motion(MuiCard)` → `motion.create(MuiCard)`
- `gui/src/components/atoms/Button.tsx`: `motion(MuiButton)` → `motion.create(MuiButton)`
- `gui/src/components/atoms/IconButton.tsx`: `motion(MuiIconButton)` → `motion.create(MuiIconButton)`

### Warning 2: metadata viewport 設定

**警告メッセージ**:
```
⚠ Unsupported metadata viewport is configured in metadata export in /. Please move it to viewport export instead.
```

**原因**: Next.js 14+では、`viewport`設定を`metadata`オブジェクトから分離し、独立した`viewport`エクスポートに移動する必要がある

**修正箇所**:
- `gui/src/app/layout.tsx`:
  - `metadata.viewport`を削除
  - `export const viewport: Viewport`を追加
  - `Viewport`型を`next`からインポート

## ✅ 修正内容

### 1. framer-motion motion() → motion.create()

**修正前**:
```typescript
const MotionCard = motion(MuiCard);
const MotionButton = motion(MuiButton);
const MotionIconButton = motion(MuiIconButton);
```

**修正後**:
```typescript
const MotionCard = motion.create(MuiCard);
const MotionButton = motion.create(MuiButton);
const MotionIconButton = motion.create(MuiIconButton);
```

### 2. metadata viewport → viewport export

**修正前** (`gui/src/app/layout.tsx`):
```typescript
import type { Metadata } from "next";

export const metadata: Metadata = {
  // ...
  viewport: "width=device-width, initial-scale=1",
  // ...
};
```

**修正後**:
```typescript
import type { Metadata, Viewport } from "next";

export const metadata: Metadata = {
  // viewport を削除
  // ...
};

export const viewport: Viewport = {
  width: "device-width",
  initialScale: 1,
};
```
