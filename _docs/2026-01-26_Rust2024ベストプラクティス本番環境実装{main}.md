### Phase 2: エラーハンドリングの改善 ✅

**対象ファイル**: `codex-rs/core/src/git4d_accelerated.rs`

**改善内容**:
1. `SESSIONS.read().unwrap()` → 適切なエラーハンドリングに置き換え
2. `SESSIONS.write().unwrap()` → `Result`型を使用したエラーハンドリング
3. エラーメッセージの明確化
4. エラーコンテキストの追加（`anyhow::Context`使用）

**改善パターン**:
```rust
// Before
let sessions = SESSIONS.read().unwrap();

// After
let sessions = SESSIONS.read()
    .map_err(|e| {
        tracing::error!("Failed to acquire read lock: {}", e);
        e
    })
    .ok()?;
```

**修正箇所**:
- `get_session()` - エラーハンドリング追加
- `list_sessions()` - エラーハンドリング追加（空のVecを返す）
- `update_session_status()` - エラーメッセージ改善
- `get_session_event_receiver()` - エラーハンドリング追加
- `remove_session()` - エラーハンドリング追加
- `launch_for_gui()` - エラーハンドリング改善
