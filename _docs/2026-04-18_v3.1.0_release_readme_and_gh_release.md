# v3.1.0 Release Readme And GH Release

## Overview

Prepared the `v3.1.0` release line for both `main` and `release/3.1.0-stable`, rewrote the public README, and packaged Windows release artifacts for GitHub Releases via `gh`.

## Background / Requirements

- Rewrite the root `README.md`
- Emphasize distinctive fork-only features instead of presenting the repo as a generic upstream mirror
- Build a Windows release artifact and package it as `tar.gz`
- Create a stable release branch with its own tag and GitHub Release
- Create a tagged GitHub Release on `main` as well

## Assumptions / Decisions

- The user explicitly approved releasing the current staged snapshot, not only the documentation-only commit.
- The stable release line uses `release/3.1.0-stable` with tag `v3.1.0-stable.0`.
- The mainline release uses tag `v3.1.0`.
- The Windows `tar.gz` bundle is the primary local release artifact for this run.

- Added a public-facing TL;DR and a dedicated unique-features section to the README.
- Kept the upstream-first positioning, but reframed the fork around pluginized differentiators such as DeepResearch, Git4D, VR or AR, and Windows-first release operations.

- Prepared this log as the release evidence trail for the branch, tag, build, package, and publish flow.
