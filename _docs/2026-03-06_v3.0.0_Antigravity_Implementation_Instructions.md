### Important GUI findings

1. `gui/next.config.mjs` still overrides webpack `splitChunks` and forcibly separates
   `three|@react-three` into a custom `three` chunk.
2. `gui/package.json` still uses:
   - `"react": "latest"`
   - `"react-dom": "latest"`
   - `"@types/react": "latest"`
   - `"@types/react-dom": "latest"`
3. `gui/src/components/visualization/Git4DVisualization.tsx` imports:
   - `Canvas`
   - `useFrame`
   - `OrbitControls`
   - `PerspectiveCamera`
   but does not actually render a React Three Fiber `<Canvas>` path in this file.
   Those imports expand the crash surface for `/git4d` and `/vr`.
4. `gui/src/components/vr/VRInterface.tsx` calls `useXR()`, but
   `gui/src/app/vr/page.tsx` renders `VRInterface` directly, outside an XR provider.
5. `gui/src/lib/api/client.ts` uses `baseUrl = 'http://localhost:8787'` and hardcodes
   `new WebSocket('ws://localhost:8787')`.
6. `gui/public/manifest.json` and `gui/public/sw.js` point at a missing
   `apple-touch-icon.png`.

## Implementation Order

### Phase 1: Finish the Rust release build

1. Let the active workspace release build finish.
2. After that completes, run the install-critical CLI rebuild:

```powershell
cd C:\Users\downl\Desktop\codex-main\codex-rs
$env:CARGO_TARGET_DIR='target-release'
$env:CARGO_INCREMENTAL='1'
Remove-Item Env:RUSTC_WRAPPER -ErrorAction SilentlyContinue
$env:SCCACHE_DISABLE='1'
cargo build --release -p codex-cli --features custom-features
```

3. Do not copy anything into `bin\` until `target-release\release\codex.exe` exists.

### Phase 2: Fix the GUI crash cluster

Apply these in order:

1. Remove the manual `splitChunks` override from `gui/next.config.mjs`.
   - This is the highest-probability fix for the shared `three-*.js` crash.
   - Treat this as a strong inference from the stack traces, not yet a formal proof.
2. Pin GUI React versions in `gui/package.json` to the currently working React 18 line:
   - `"react": "18.3.1"`
   - `"react-dom": "18.3.1"`
   - `"@types/react": "18.3.1"`
   - `"@types/react-dom": "18.3.1"`
3. Remove unused `@react-three/fiber` and `@react-three/drei` imports from
   `gui/src/components/visualization/Git4DVisualization.tsx` if they are not required.
4. Fix `/vr` provider usage:
   - either render `VRInterface` only under a valid XR provider
   - or temporarily gate the component until the provider tree is in place
5. Fix release-safe frontend configuration:
   - derive WebSocket URL from `this.baseUrl`
   - replace the missing `apple-touch-icon.png` reference with a real asset path
