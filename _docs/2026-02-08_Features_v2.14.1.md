# Codex v2.14.1 Feature Log

## Overview

- **Version**: v2.14.1
- **Date**: 2026-02-08
- **Focus**: QA Agent Integration, GUI-X, and System Hardening

## New Features

### 1. QA Agent & A2A Swarm Intelligence

- **Real-time Linting**: The QA Agent now performs real-time linting and static analysis on code changes, broadcasting results via the A2A (Agent-to-Agent) protocol.
- **A2A Broadcast**: Implemented `a2a_broadcast` to enable seamless communication between the Backend, Frontend, and QA agents. This allows for coordinated actions and immediate feedback loops during development.
- **Self-Correction**: The QA Agent can autonomously trigger fix workflows for common linting errors.

### 2. Codex GUI-X

- **Modern Tech Stack**: Rebuilt using **Next.js 15**, **React 19**, and **Proton** for a high-performance, native-like experience.
- **Material UI Design**: Adopted Material UI (MUI) for a sleek, professional, and accessible interface.
- **3D Visualization**: Integrated `Three.js` (via `@react-three/fiber`) to provide immersive 3D visualizations of the codebase architecture (Git4D).
- **Bridge Architecture**: valid bi-directional communication between the Rust backend and the GUI frontend.

### 3. System Upgrades & Hardening

- **Rust 2024**: Full migration to Rust 2024 edition, leveraging the latest language features for memory safety and concurrency.
- **Zero-Warning Compilation**: Achieved a clean build state with 0 warnings for core crates (`mcp-server`, `tui`, `core`), ensuring high reliability.
- **CI/CD Optimization**: Improved GitHub Actions workflows for faster release cycles and stricter quality gates.

## Technical Details

- **Protocol**: Strictly aligned with `codex_protocol` and MCP 1.0 specifications.
- **Security**: Enhanced Windows sandbox leveraging Job Objects and ACLs for secure execution of untrusted code.
