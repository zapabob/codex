🚀 **Announcing Codex v2.17.0 — The AI Agent That Can Be Used BY Other AIs**

Most AI dev tools help you write code. Very few can become a **tool for other AI agents** themselves.

**Codex is the exception.**

Forked from OpenAI's official codex and rebuilt in **Rust 2024 edition**, this is not a code autocomplete plugin. It's an enterprise-grade **autonomous AI engineering platform** with MCP dual-mode, multi-agent orchestration, WebXR visualization, and kernel-level sandboxing.

---

**🔌 MCP Dual-Mode — The Core Differentiator**

Codex doesn't just _consume_ MCP tools — it _exposes_ itself as one.
Claude, Cursor, or any MCP-compatible agent can call Codex's coding capabilities as a first-class tool.
v2.17.0 adds OAuth callback URL configuration and network proxy support.

**🤖 Multi-Agent Orchestration**

A 4-stage pipeline: Planner → Assigner → Executor → Aggregator.
Specialized sub-agents run in full isolation (separate Git worktrees) with **2.59× measured speedup** over sequential execution. Semantic conflict detection handles merge scenarios automatically.

**🛡️ Kernel-Level Zero-Trust Sandbox**

Win32 Job Objects (Windows) · Landlock LSM + seccomp-bpf (Linux) · Seatbelt (macOS).
Not userspace sandboxing — **the kernel itself enforces process isolation** at every system call.

**🎮 WebXR Git Visualization (Git4D)**

Commit history as an immersive 4D space-time graph with Three.js + WebXR.
Meta Quest 2/3 hand tracking, cyberpunk GLSL shaders. Launch with `/VRChat` from the TUI.

**⚡ Engineering Highlights**

- Rust 2024 · Tokio async · 69-crate workspace
- Zero compiler warnings (MILSPEC-grade build discipline)
- CUDA 3.74× GPU acceleration · 6-core sccache parallel builds
- Playwright E2E + cargo-nextest for full CI/CD coverage
