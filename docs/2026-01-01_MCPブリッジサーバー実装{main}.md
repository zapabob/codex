# MCPブリッジサーバー実装ログ

## 実装日時
2026-01-01

## 概要
CLIとChrome拡張機能間の通信をMCP（Model Context Protocol）経由で行うブリッジサーバーを実装しました。これにより、より堅牢で標準化された通信が可能になります。

## 実装内容

### 1. MCPブリッジサーバープロジェクト作成
- **ファイル**: `codex-rs/chrome-mcp-bridge/Cargo.toml`
- **内容**: 
  - Rustプロジェクト設定
  - `mcp-types`、`rmcp`、`tokio`、`serde`などの依存関係を定義
  - stdioとstreamable HTTPの両方をサポート

### 2. ブリッジサーバーの基本実装
- **ファイル**: `codex-rs/chrome-mcp-bridge/src/main.rs`
- **ファイル**: `codex-rs/chrome-mcp-bridge/src/bridge.rs`
- **内容**:
  - stdioモード: CLIからの接続を受け付ける
  - HTTPモード: 拡張機能からの接続を受け付ける（ポート8788）
  - メッセージルーティング機能
  - セッション管理機能

### 3. MCPツール定義
- **ファイル**: `codex-rs/chrome-mcp-bridge/src/tools.rs`
- **内容**:
  - `dom_read`: DOM読み取りツール
  - `console_get_logs`: コンソールログ取得ツール
  - `network_get_logs`: ネットワークログ取得ツール

### 4. CLIのMCPクライアント実装
- **ファイル**: `codex-rs/cli/src/chrome_cmd.rs`
- **内容**:
  - `run_dom_via_mcp()`: MCP経由でDOM読み取り
  - `run_console_via_mcp()`: MCP経由でコンソールログ取得
  - `run_network_via_mcp()`: MCP経由でネットワークログ取得
  - `find_mcp_bridge_binary()`: MCPブリッジバイナリの検索
  - 既存のnative messaging hostへのフォールバック機能

### 5. 拡張機能のMCPクライアント実装
- **ファイル**: `extensions/chrome-codex/background/background.js`
- **ファイル**: `extensions/chrome-codex/background/mcp_client.js`
- **内容**:
  - JavaScript MCPクライアントクラス
  - streamable HTTP経由でブリッジサーバーに接続
  - `dom.read.request`、`console.get_logs.request`、`network.get_logs.request`のMCP対応
  - 既存のnative messaging hostへのフォールバック機能

### 6. ドキュメント更新

## 技術詳細

### アーキテクチャ
```
CLI (codex chrome dom/console/network)
  ↓ (stdio MCP)
MCP Bridge Server
  ↓ (streamable HTTP MCP)
Chrome Extension (background.js)
  ↓
Content Script
```

### 通信フロー
1. CLIがMCPブリッジサーバーにstdio経由で接続
2. ブリッジサーバーが拡張機能にstreamable HTTP経由でリクエストを転送
3. 拡張機能がContent Script経由で実際の操作を実行
4. 結果がブリッジサーバー経由でCLIに返却

### フォールバック機能
- CLIはMCPブリッジが利用できない場合、既存のnative messaging hostに自動的にフォールバック
- 拡張機能もMCPブリッジが利用できない場合、既存のnative messaging hostに自動的にフォールバック

## 使用方法

### ビルド
```bash
cargo build -p codex-chrome-mcp-bridge --release
```

### 実行
**stdioモード（CLI用）:**
```bash
codex-chrome-mcp-bridge stdio
```

**HTTPモード（拡張機能用）:**
```bash
codex-chrome-mcp-bridge http 8788
```

### CLIコマンド
```bash
# MCP経由でDOM読み取り（自動的にMCPブリッジを使用）
codex chrome dom --selector "#main-content"

# MCP経由でコンソールログ取得
codex chrome console --filter "error" --limit 50

# MCP経由でネットワークログ取得
codex chrome network --filter "api" --limit 50
```

## 今後の改善点

1. **完全なHTTP実装**: 現在のHTTPモードは基本的な実装のみ。完全なstreamable HTTP MCPトランスポートの実装が必要
2. **拡張機能との統合**: 拡張機能がMCPブリッジサーバーに自動接続する機能
3. **エラーハンドリングの強化**: より詳細なエラーメッセージとリトライ機能
4. **認証機能**: セキュリティのための認証機能の追加
5. **テスト**: エンドツーエンドテストの追加
