## 使用方法

### 高速差分ビルド

```bash
# 高速差分ビルド（クリーンをスキップ）
npm run build:binary:fast

# または
node scripts/build-binary.js --skip-clean
```

### 統合ビルド・インストール

```bash
# 高速差分ビルドとインストール
npm run build-and-install:fast

# グローバルインストール付き
node scripts/build-and-install.js --skip-clean --global
```

### npm/pnpmインストール

```bash
# npmでインストール
npm install -g @zapabob/codex

# pnpmでインストール
pnpm add -g @zapabob/codex

# npxで実行
npx @zapabob/codex --version

# pnpm execで実行
pnpm exec codex --version
```

## 注意事項

1. **Visual Studio Build Tools**: `aws-lc-sys`のビルドにはVisual Studio Build Toolsが必要です。ビルドが失敗する場合は、既存バイナリが使用されます。

2. **ESMモジュール警告**: `bin/codex.js`がESMモジュールとして動作するため、`package.json`に`"type": "module"`を追加することを推奨します。

3. **プロセスキル**: 実行中の`codex`, `codex-tui`, `codex-tauri-gui`プロセスは自動的に強制終了されます。

4. **差分ビルド**: 初回ビルド時には差分ビルドの効果はありません。2回目以降のビルドで効果が発揮されます。

## 今後の改善点

1. `package.json`に`"type": "module"`を追加してESMモジュール警告を解消
2. Visual Studio Build Toolsの設定を改善して`aws-lc-sys`のビルドを成功させる
3. GitHub Releasesからのバイナリダウンロード機能の実装（`install-binary.js`に既に実装済み）
