## 🎮 利用方法

### npmパッケージ (推奨)
```bash
npm install -g @zapabob/codex
codex --version  # codex-cli 2.2.0
```

### CLI使用例
```bash
# Planモード
codex plan create "認証システム実装" --mode=orchestrated --budget-tokens=50000

# サブエージェント委任
codex delegate code-reviewer --scope ./src

# Git 4D可視化
codex git-analyze --cuda

# Deep Research
codex research "Rust async best practices" --depth 3 --strategy comprehensive
```

### GUI/Webインターフェース
```bash
# バックエンド起動
cargo run -p codex-gui

# フロントエンド起動
cd gui && npm run dev

# ブラウザで http://localhost:3000 にアクセス
```
