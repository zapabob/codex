## 🔧 実行手順

### 1. 既存プロセスの停止

```powershell
Get-Process codex -ErrorAction SilentlyContinue | Stop-Process -Force
```

### 2. ビルドディレクトリへの移動

```powershell
Set-Location C:\Users\downl\Desktop\codex-main\codex-rs
```

### 3. 高速差分ビルド

```powershell
cargo build --release -p codex-cli
```

**実行モード**: バックグラウンド実行  
**ビルド対象**: `codex-cli`クレートのみ（差分ビルド）

### 4. バイナリの上書きインストール

```powershell
cargo install --path cli --bin codex --force
```

**実行モード**: バックグラウンド実行  
**オプション**: `--force`（既存バイナリを上書き）
