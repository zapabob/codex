# _doc 実装ログ自動生成ディレクトリ

AIオーケストレーションで生成される自動実装ログを格納する専用ディレクトリです。`scripts/create-implementation-log.js` を通じて日付・ワークツリー名・担当エージェントなどのメタデータが付与された Markdown ファイル（例: `_doc/2025-11-17-main実装ログ.md`）が生成されます。

- 既存の `_docs/` 手動ログとは別に、自動生成ログを体系的に保存します。
- 各サブエージェントは実装開始前に最新の `_doc/*.md` を確認し、直前の変更内容・QC 判断・統計結果を引き継いでください。
