# 並列Git仮想OS拡張プラン

## 方針ざっくり

- 並列エージェント実行の計測値を収集し、ガウス分布・分散分析・QC指標・量子最適化ログまで一括で吐き出す分析パイプラインを `codex-core` に増設
- Tauri 側に分析API／GitHub Actions連携／WSL+Hyper-V制御ブリッジを追加し、WindowsでもLinux/Mac体験を抽象化
- React+Babylon/Three UI をダッシュボード化し、ガントチャート・かんばん・QCカード・GitHub Actionタイムラインを追加
- Python (`py -3`) で統計/最適化補助スクリプトを走らせ、TypeScript/Rustとも警告ゼロを維持しつつ差分ビルドと強制再インストール動線を整える
