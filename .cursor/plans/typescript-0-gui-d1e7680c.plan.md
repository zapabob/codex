# テスト実行とカバレッジCI統合計画

## 1. ローカルでのテスト実行とカバレッジ確認

### 1.1 テスト実行

**コマンド**: `codex-rs/tauri-gui`ディレクトリで実行

```bash
npm run test:coverage
```

**確認項目**:

- すべてのテストがパスするか
- カバレッジレポートが生成されるか
- カバレッジが95%以上（statements, branches, functions, lines）か

### 1.2 カバレッジレポートの確認

**レポート形式**:

- HTML: `coverage/index.html` - ブラウザで確認
- テキスト: コンソール出力
- JSON: `coverage/coverage-final.json` - プログラムで解析可能

**確認手順**:

1. `npm run test:coverage`を実行
2. `coverage/index.html`をブラウザで開いて確認
3. カバレッジ不足箇所を特定
4. 必要に応じてテストを追加

### 1.3 カバレッジ閾値チェック

**コマンド**:

```bash
npm run test:coverage:threshold
```

**確認項目**:

- すべてのメトリクス（lines, branches, functions, statements）が95%以上か
- 閾値を下回る場合、エラーで終了するか
