## 実装フェーズ

### Phase 1: API変更への対応

#### 1.1 `ReasoningSummaryFormat`の削除対応

**ファイル**: `codex-rs/core/src/models_manager/model_family.rs`

**問題**: `codex_protocol::openai_models::ReasoningSummaryFormat`が存在しない

**対応**:

- `ReasoningSummaryFormat`の使用箇所を確認
- `codex_protocol::config_types::ReasoningSummaryFormat`に置換、または削除
- `model_family.rs`の6行目のインポートを修正

#### 1.2 `ModelClient::new`の引数修正

**ファイル**: `codex-rs/core/src/agents/runtime.rs` (3箇所: 242行目, 597行目, 1288行目)

**問題**: `ModelClient::new`は`ModelInfo`を要求するが、`ModelFamily`を渡している

**対応**:

- `ModelFamily`から`ModelInfo`への変換関数を作成または使用
- `find_family_for_model`で取得した`ModelFamily`から`ModelInfo`を生成
- `ModelInfo::from_model_family()`のようなヘルパー関数を実装

**修正例**:

```rust
let model_info = ModelInfo::from_family(model_family);
let model_client = ModelClient::new(
    config.clone(),
    auth_manager.clone(),
    model_info,  // ModelFamilyではなくModelInfo
    otel_manager,
    provider,
    reasoning_effort,
    reasoning_summary,
    conversation_id,
    session_source,
);
```

#### 1.3 `ResponseItem::Message`の`end_turn`フィールド追加

**ファイル**: `codex-rs/core/src/agents/runtime.rs` (3箇所: 248行目, 652行目, 1332行目)

**問題**: `ResponseItem::Message`に`end_turn: Option<bool>`フィールドが必要

**対応**:

- すべての`ResponseItem::Message`作成箇所に`end_turn: None`を追加

**修正例**:

```rust
ResponseItem::Message {
    role: "user".to_string(),
    content: content,
    end_turn: None,  // 追加
}
```

#### 1.4 `Prompt`構造体のフィールド修正

**ファイル**: `codex-rs/core/src/agents/runtime.rs` (3箇所: 258行目, 667行目, 1344行目)

**問題**: `Prompt`に`base_instructions_override`フィールドがない（`base_instructions`のみ）

**対応**:

- `base_instructions_override`を削除し、`base_instructions`に統合
- `base_instructions`が`BaseInstructions`型であることを確認

**修正例**:

```rust
let prompt = Prompt {
    input: input_items,
    tools: vec![],
    parallel_tool_calls: false,
    base_instructions: BaseInstructions::from_string(system_prompt),  // 修正
    personality: None,
    output_schema: None,
};
```

#### 1.5 `ModelClient::stream`メソッドの確認と修正

**ファイル**: `codex-rs/core/src/agents/runtime.rs` (3箇所: 279行目, 678行目, 1365行目)

**問題**: `ModelClient`に`stream`メソッドがない

**対応**:

- `ModelClientSession`のメソッドを確認
- `client_session.stream(&prompt)`または`client_session.request_stream(&prompt)`に変更
- 正しいメソッド名を`codex-rs/core/src/client.rs`で確認

### Phase 2: 型定義エラーの修正

#### 2.1 `user_shell.rs`の`command`フィールド修正

**ファイル**: `codex-rs/core/src/tasks/user_shell.rs`

**問題**: `self.command`が`String`だが、`Vec<String>`として扱おうとしている

**対応**:

- `UserShellTask`構造体の`command`フィールドの型を確認
- `String`の場合は`Vec<String>`に変更、または`command.split_whitespace().collect()`で変換
- 84-88行目、123行目、125行目を修正

**修正例**:

```rust
// commandフィールドがStringの場合
let command_vec: Vec<String> = self
    .command
    .split_whitespace()
    .map(|s| s.to_string())
    .collect();
```

#### 2.2 `model_family.rs`の複数エラー修正

**ファイル**: `codex-rs/core/src/models_manager/model_family.rs`

**問題**:

- `config.model_reasoning_summary_format`フィールドが存在しない
- `ModelInfo`のフィールド不一致
- 型推論エラー

**対応**:

- 91行目: `config.model_reasoning_summary_format`を`config.model_reasoning_summary`に変更
- 112-134行目: `ModelInfo`のパターンマッチに不足フィールドを追加（`model_instructions_template`, `auto_compact_token_limit`, `effective_context_window_percent`）
- 120行目、132行目: 存在しないフィールド（`minimal_client_version`, `reasoning_summary_format`）を削除
- 136行目: `default_reasoning_level`が`Option<ReasoningEffort>`の場合、`unwrap_or`で処理
- 138行目: `base_instructions`が`String`の場合、`Option<String>`への変換を修正
