# 公式最新変更取り込みと独自機能維持プラン

## 現状分析

### 現在の状態

- **ブランチ**: `merge-upstream-2025-12-20`
- **マージ状況**: upstream/mainは既にマージ済み（HEAD..upstream/mainが空）
- **問題点**: 
- `target/fast/` 配下のビルド成果物が大量にステージングされている
- `.gitignore` に `target/` が含まれていない
- ビルドエラーが残っている（前回のセッションから継続）

### 公式の最新変更（既にマージ済み）

1. **機能削除**

- `undo`機能の削除 (#8424)
- `plan`機能をsystem skillsから削除 (#8374)
- `rmcp`機能とexp flagの削除 (#8087)

2. **バグ修正**

- TUI2: トランスクリプトマウス選択境界の修正 (#8419)
- アルファ版でのパニック修正 (#8406)
- TUI2: スクロール入力の調整 (#8357)

3. **依存関係更新**

- clap 4.5.53
- landlock 0.4.4
- openssl-sys 0.9.111
- test-log 0.2.19
- tracing-opentelemetry 0.32.0

### 独自機能（維持対象）

1. **orchestration**: `codex-rs/core/src/orchestration/`

- auto_orchestrator, collaboration_store, conflict_resolver, parallel_execution, plan_orchestrator

2. **agents**: `codex-rs/core/src/agents/`

- runtime, competition, types, loader, budgeter

3. **deep-research**: `codex-rs/deep-research/`
4. **plan機能**: `codex-rs/core/src/plan/`（公式では削除済みだが独自実装として維持）

## 実装手順

### Phase 1: ビルド成果物の除外設定

1. **`.gitignore` の更新**

- `target/` を追加（ビルド成果物を除外）
- `target/fast/` も除外されることを確認

2. **既にステージングされているファイルのアンステージ**

- `git reset HEAD target/` でビルド成果物をアンステージ
- 必要に応じて `git clean -fd target/` で未追跡ファイルを削除

### Phase 2: ビルドエラーの修正

1. **残っているビルドエラーの確認**

- `cargo build -p codex-cli -p codex-tui --release` を実行
- エラーメッセージを確認

2. **エラーの修正**

- 型不一致、未解決インポート、プライベートアクセスなどのエラーを修正
- 公式APIに準拠させつつ独自機能を維持

### Phase 3: 独自機能の公式API準拠確認

1. **orchestrationモジュール**

- 公式のAPI変更に合わせてインターフェースを調整
- 内部実装は独自機能を維持

2. **agentsモジュール**

- 公式のskills APIに合わせて調整
- 独自の並列実行機能は維持

3. **plan機能**

- 公式では削除されているため、非公式機能として明確化
- 必要に応じてコメントで「zapabob独自機能」と明記

### Phase 4: テストとリンター

1. **ビルド確認**

- `cargo build --all-features` でビルドエラーを確認
- エラーがあれば修正

2. **テスト実行**

- `cargo test --all-features` でテストを実行
- 失敗したテストを修正

3. **リンター確認**

- `cargo clippy --all-features -- -D warnings` で警告を確認
- 警告があれば修正
