# Rust 2024警告0型定義完璧ビルドインストール計画

## 目標

- Rust 2024 editionに統一（3つのクレートを更新）
- 型定義を完璧に（エラー0）
- 警告0を達成
- Windows 11 25H2とCodexのベストプラクティスに準拠
- 高速差分ビルドでCLI/TUI/GUIを強制インストール

## 実装手順

### 1. Rust 2024 editionへの統一

**対象ファイル**:

- `codex-rs/windows-sandbox-rs/Cargo.toml`: `edition = "2021"` → `edition = "2024"`
- `codex-rs/utils/pty/Cargo.toml`: `edition = "2021"` → `edition = "2024"`
- `codex-rs/gui/Cargo.toml`: `edition = "2021"` → `edition = "2024"`

**確認事項**:

- Rust 2024 editionは後方互換性があるため、通常は問題なし
- 変更後、`cargo check`で互換性を確認

### 2. 型エラーの確認と修正

**確認コマンド**:

```powershell
cd codex-rs
cargo check --release -p codex-cli -p codex-tui 2>&1 | Select-String -Pattern "error\[E"
```

**修正対象**（ログから推測）:

- `codex-rs/core/src/state/service.rs`: `exec_command`と`executor`のインポートエラー（既に修正済みの可能性あり）
- `codex-rs/core/src/tools/mod.rs`: 型定義の確認（既に正しく実装されている可能性あり）
- その他の型エラーがあれば修正

**修正方法**:

- 未解決のインポートがあれば、正しいパスに修正
- 型の不一致があれば、適切な型に修正
- `cargo check`でエラー0を確認

### 3. 警告0の達成

**確認コマンド**:

```powershell
cargo clippy --release -p codex-cli -p codex-tui -- -W clippy::all 2>&1 | Select-String -Pattern "warning:"
```

**修正対象**:

- `codex-rs/deep-research/src/mcp_search_provider.rs`: 未使用フィールド`api_key`の警告
- 未使用の`use`文を削除
- 未使用変数に`_`プレフィックスを付与
- Clippyの警告に従ってコードを改善

**修正方法**:

- 未使用フィールド: `#[allow(dead_code)]`を追加するか、実際に使用する
- 未使用インポート: 削除
- 未使用変数: `_`プレフィックスを付与
- その他のClippy警告: 警告内容に従って修正

### 4. 高速差分ビルドの実行

**スクリプト**: `codex-rs/fast-build-install.ps1`（既存）

**実行内容**:

- `-Clean`フラグなしで実行（差分ビルド）
- `cargo build --release -p codex-cli -p codex-tui`を実行
- tqdm風の進捗表示で可視化
- エラー数と警告数を集計
- エラー0・警告0を確認

**GUIビルド**:

- `-All`フラグでGUIもビルド（オプション）
- `tauri-gui`ディレクトリのビルドスクリプトを実行

### 5. 強制インストール

**実行内容**:

- 起動中の`codex`プロセスを停止
- `cargo install --path cli --force`でCLIを上書きインストール
- `cargo install --path tui --force`でTUIをインストール（必要に応じて）
- GUIのMSIインストーラーを実行（`-All`フラグ時）

### 6. 動作確認と統計表示

**確認項目**:

- `codex --version`でインストール確認
- エラー数: 0
- 警告数: 0
- ビルド時間の表示
- 総時間の表示

## 期待される結果

- Rust 2024 editionに統一完了
- 型定義が完璧でエラー0件
- 警告0件
- 機能が維持されている
- CLI/TUI/GUIの強制インストール成功
- tqdm風の可視化で進捗が分かりやすい
- Windows 11 25H2とCodexのベストプラクティスに準拠

## 注意事項

- 差分ビルドなので、`cargo clean`は実行しない（`-Clean`フラグなし）
- ビルド中にエラーや警告が検出された場合は、修正してから再ビルド
- プロセス停止は確実に実行して、ファイルロックを回避
- インストール前に必ずプロセスを停止
