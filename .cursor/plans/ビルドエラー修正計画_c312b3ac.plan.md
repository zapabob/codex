# ビルドエラー修正計画

## エラー概要

現在のビルドで以下のコンパイルエラーが発生しています：

1. **codex-core (test "performance_tests")**: temporary value dropped while borrowed (line 117)
2. **codex-app-server (lib test)**: 型不一致エラー（UnboundedSender vs Sender、8箇所）
3. **codex-app-server (lib test)**: RateLimitSnapshotのフィールド不足（credits, plan_type）

## 修正内容

### 1. codex-core/tests/performance_tests.rs の修正

**ファイル**: `codex-rs/core/tests/performance_tests.rs`

**問題**: `runtime.delegate()`の戻り値が一時値として扱われ、`tasks.push(task)`で借用エラーが発生

**修正方法**: `delegate()`の戻り値の型を確認し、適切に保存する。おそらく`impl Future`を返しているため、`Box::pin()`でpinするか、直接`join_all`に渡す。

```rust
// 修正前（line 114-123）
let mut tasks = Vec::new();
for i in 0..10 {
    let task = runtime.delegate(...);
    tasks.push(task);  // エラー: temporary value dropped
}

// 修正後
let tasks: Vec<_> = (0..10).map(|i| {
    runtime.delegate(
        "throughput-test",
        &format!("Task {}", i),
        HashMap::new(),
        Some(3000),
        None,
    )
}).collect();
```

または、`delegate()`が`impl Future`を返す場合：

```rust
let mut tasks = Vec::new();
for i in 0..10 {
    let task = Box::pin(runtime.delegate(...));
    tasks.push(task);
}
```

### 2. codex-app-server/src/bespoke_event_handling.rs の修正

**ファイル**: `codex-rs/app-server/src/bespoke_event_handling.rs`

**問題**: `mpsc::channel`を使用しているが、`OutgoingMessageSender::new`は`UnboundedSender`を期待

**修正箇所**: 以下の8箇所

- Line 1363-1364
- Line 1405-1406
- Line 1446-1447
- Line 1481-1482
- Line 1533-1534
- Line 1618-1619
- Line 1684-1685
- Line 1929-1930
- Line 1965-1966

**修正方法**: `mpsc::channel(CHANNEL_CAPACITY)`を`mpsc::unbounded_channel()`に変更

```rust
// 修正前
let (tx, mut rx) = mpsc::channel(CHANNEL_CAPACITY);

// 修正後
let (tx, mut rx) = mpsc::unbounded_channel();
```

### 3. codex-app-server/src/outgoing_message.rs の修正

**ファイル**: `codex-rs/app-server/src/outgoing_message.rs`

**問題**: `RateLimitSnapshot`構造体に`credits`と`plan_type`フィールドが不足

**修正箇所**: Line 211-218

**修正方法**: `RateLimitSnapshot`の初期化に`credits: None`と`plan_type: None`を追加

```rust
// 修正前
rate_limits: RateLimitSnapshot {
    primary: Some(RateLimitWindow { ... }),
    secondary: None,
},

// 修正後
rate_limits: RateLimitSnapshot {
    primary: Some(RateLimitWindow { ... }),
    secondary: None,
    credits: None,
    plan_type: None,
},
```

## 注意事項

- `mpsc::unbounded_channel()`は容量制限がないため、メモリ使用量に注意が必要ですが、テストコードなので問題ありません
- `delegate()`の戻り値の型が`impl Future`の場合、`Box::pin()`が必要になる可能性があります
