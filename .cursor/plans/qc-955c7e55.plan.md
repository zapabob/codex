# TUI最新機能マージ計画

## 概要

upstream/mainからTUI関連の最新変更を取り込み、独自機能を保持しながらマージし、ビルドと起動テストまで実施します。

## ステップ

### Phase 1: 下準備と差分確認

- `git fetch upstream` で最新mainを取得
- `git status` / `git diff upstream/main -- codex-rs/tui` などで現状差分と独自変更を把握

### Phase 2: マージ (ours優先ベース)

- `git merge upstream/main -X ours` で全体を ours 優先でマージ
- コンフリクトが発生したTUI関連ファイル（例: `codex-rs/tui/src/**`, `codex-rs/tui/Cargo.toml`, `codex-rs/cli/src/main.rs` のTUI起動ロジックなど）を個別に精査
- 上流の新機能コードを取り込みつつ、独自機能や設定は維持（必要に応じて手動マージ）

### Phase 3: ビルドと依存関係更新

- `just tui-build` または `cargo build --release -p codex-tui`
- 依存関係更新が必要な場合は `cargo update -p <crate>` で対応

### Phase 4: 起動確認

- `codex tui` でTUIを起動し、主要機能（画面表示、エージェント操作など）が動作するか手動確認

### Phase 5: 実装ログ作成

- `_docs/` に `yyyy-mm-dd_TUI最新マージ完了.md` を作成し、マージ内容・ビルド結果・起動確認結果・残課題を記録
