## 実装フェーズ

### Phase 1: 公式リポジトリ統合と差分分析

#### 1.1 Upstream最新取得と差分分析

- **対象**: `scripts/check-upstream-diff.ps1`を実行
- **作業内容**:
  - `git fetch upstream`で最新を取得
  - `git diff upstream/main...main`で差分確認
  - 重要なコミット（バグフィクス、セキュリティ修正）を特定
  - 脆弱性更新（CVE対応）を確認

#### 1.2 独自機能の保護戦略

- **対象**: `codex-rs/core/Cargo.toml`の`custom-features`フラグ
- **作業内容**:
  - 独自機能を`#[cfg(feature = "custom-features")]`で保護
  - 公式機能と同等の独自機能を特定
  - 統合戦略を決定（公式機能に独自機能の利点を統合）

#### 1.3 マージ実行

- **対象**: `git merge upstream/main`
- **作業内容**:
  - コンフリクト解決（公式の変更を優先、独自機能は保護）
  - ビルド検証（`cargo build --features custom-features`）
  - テスト実行（`cargo test --features custom-features`）
