# CI/CD失敗修正計画

## 問題の分析

すべてのCI/CDワークフローが失敗している原因として、以下が考えられます：

1. **Rust 2024 editionでのunsafe関数呼び出し**: `env::set_var`と`env::remove_var`がunsafe関数になったため、unsafeブロックが必要
2. **最近修正したビルドエラー**: ローカルでは修正済みだが、CI環境で再現している可能性
3. **テストフィクスチャファイル**: `task_details_with_error.json`がCI環境に存在しない可能性

## 修正内容

### 1. integration_web_search.rsのunsafe関数呼び出し修正

**ファイル**: `codex-rs/deep-research/tests/integration_web_search.rs`

**問題**: ユーザーがunsafeブロックを削除したが、Rust 2024 editionでは`env::set_var`と`env::remove_var`はunsafe関数

**修正箇所**:

- Line 15: `env::set_var("BRAVE_API_KEY", &api_key)` → unsafeブロックで囲む
- Line 35-36: `env::set_var("GOOGLE_API_KEY", ...)` → unsafeブロックで囲む
- Line 54: `env::set_var("BING_API_KEY", ...)` → unsafeブロックで囲む
- Line 85-88: `env::remove_var(...)` → unsafeブロックで囲む
- Line 113: `env::set_var("BRAVE_API_KEY", ...)` → unsafeブロックで囲む

**修正方法**:

```rust
// 修正前
env::set_var("BRAVE_API_KEY", &api_key);

// 修正後
unsafe {
    env::set_var("BRAVE_API_KEY", &api_key);
}
```

### 2. CIワークフローでのテスト実行確認

**確認事項**:

- `rust-ci.yml`の`cargo nextest run --all-features`がすべてのテストを実行
- `subagent-ci.yml`の`cargo test`が個別クレートのテストを実行
- `ci.yml`のMCP統合テストが実行される

**影響を受ける可能性のあるテスト**:

- `codex-core/tests/performance_tests.rs` - 修正済み
- `codex-app-server/src/bespoke_event_handling.rs`のテスト - 修正済み
- `codex-backend-client`のテスト - `task_details_with_error.json`が必要

### 3. その他の潜在的な問題

**確認が必要な項目**:

- `cargo clippy -- -D warnings`で警告がエラーとして扱われる
- `cargo fmt --check`でフォーマットチェックが実行される
- 個別クレートの`cargo check`が実行される（`rust-ci.yml` line 276-282）

## 実装手順

1. `integration_web_search.rs`のunsafe関数呼び出しを修正（5箇所）
2. 修正が正しいか確認（`cargo check`でコンパイルエラーがないか）
3. 必要に応じて他のテストファイルも確認
4. CIワークフローが正常に動作するか確認（GitHub Actionsで実行）

## 注意事項

- Rust 2024 editionでは`env::set_var`と`env::remove_var`はunsafe関数です
- テストコードでもunsafeブロックが必要です
- `test_duckduckgo.rs`は既にunsafeブロックが追加されているので問題なし
- CI環境では`--all-features`フラグでテストが実行されるため、すべての機能が有効になります
