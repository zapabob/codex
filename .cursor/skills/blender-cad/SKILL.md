# Blender CAD Agent Skill (Cursor Edition)

## Overview

Blender CAD modeling automation skill for Cursor IDE. Automates Blender Python scripting workflows.

## Capabilities

- STEP/IGES CAD import
- Geometry Nodes parametric design
- Material management
- Render automation
- Multi-format export (FBX, OBJ, USD, glTF)

## Usage

```bash
codex $blender-cad "Import STEP file and create CAD model"
```
