# VRChat Dev Agent Skill (Cursor Edition)

## Overview

VRChat world and avatar development skill for Cursor IDE. Automates VRChat SDK3 development workflows.

## Capabilities

- UdonSharp development and compilation
- World building and optimization
- Avatar configuration with modularavatar
- PhysBones and contact systems
- Shader integration (liltoon, Poiyomi)

## Usage

```bash
codex $vrchat-dev "Create VRChat world with interactive objects"
```
