Release proof

Built, installed, and checked on Windows.

The shipped executable reports codex-cli 3.2.0. The release path used six build jobs, isolated H: target and temp directories, Bazel lock refresh, focused app-server protocol tests, and a tar.gz asset with merge evidence.

  1. cargo test -p codex-app-server-protocol git4d
  2. cargo test -p codex-app-server git4d
  3. cargo check -p codex-core -j 6
  4. cargo check -p codex-app-server -j 6
  5. cargo check -p codex-tui -j 6
  6. cargo build --release -p codex-cli -j 6
