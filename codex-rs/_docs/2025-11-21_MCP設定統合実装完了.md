##  設定ファイル例

### .cursor/mcp.json
`json
{
  "mcpServers": {
    "codex": {
      "command": "codex",
      "args": ["mcp-server"],
      "env": {
        "RUST_LOG": "info",
        "OPENAI_API_KEY": ""
      }
    },
    "playwright": {
      "command": "npx",
      "args": ["-y", "@playwright/mcp@latest"],
      "env": {}
    }
  }
}
`

### 使用方法
`ash
# 外部サーバー一覧取得
codex mcp-server  # MCPサーバー起動
# クライアントから: external_mcp_list_servers ツール呼び出し

# サーバー起動
external_mcp_start_server {"server_name": "playwright"}

# ステータス確認
external_mcp_get_server_status {"server_name": "playwright"}
`
